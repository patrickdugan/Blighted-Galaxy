# Stories: surviving narrative archive

Four recovered source manuscripts, copied byte-for-byte at the **Git blob** level from the existing \`recovery/manuscripts/\` text transcriptions. The extraction kept page markers and occasional line-wrap artifacts. These are historical drafts, not revised canon. The original user-supplied Word binaries and illustration are not present in this repository yet.

## Preservation rule

These texts are creative source evidence. Editorial changes, continuity reconciliations, polished fiction and adaptations should be committed to \`stories/editions/\` as new files with explicit lineage.
